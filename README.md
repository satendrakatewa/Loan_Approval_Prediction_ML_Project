# Loan_Approval_Prediction_ML_Project

This project uses a Random Forest Classifier to predict loan approval based on applicant information.

## Features

- Data cleaning and preprocessing
- Exploratory Data Analysis (EDA)
- Feature engineering
- Model training and evaluation
- Manual prediction interface
- Saved trained model for reproducibility

## Project Structure

- `notebook/`: Jupyter Notebook with code
- `model/`: Saved model files (`.pkl`)
- `data/`: Dataset (or sample data)
